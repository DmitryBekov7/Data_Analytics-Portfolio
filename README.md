# Data_Analytics-Portfolio
---

Начинающий аналитик данных, сейчас развиваюсь в сторону продуктовой и веб-аналитики: собираю портфолио из учебных, тестовых и личных проектов, в которых отрабатываю SQL, Python, визуализацию и статистику.

В этом репозитории собраны выполненные мной проекты, демонстрирующие мои компетенции в сфере дата-аналитики. Часть работ — тестовые задания и самостоятельные пет-проекты, часть — учебные и рабочие задачи. Планирую активно пополнять портфолио.

*Общее количество проектов в репозитории:* **6**

## Структура репозитория

---

### Проекты SQL и веб-аналитика
---

#### [Аналитика сайта автодилера по логам Яндекс.Метрики (тестовое задание TradeDealer)](https://github.com/DmitryBekov7/Data_Analytics-Portfolio/tree/main/TestWork_toretto)

Проект, демонстрирующий навыки написания SQL-запросов в Google BigQuery, работы с сырыми логами Яндекс.Метрики (Logs API) и расчёта продуктовых и веб-метрик: топ брендов и моделей по просмотрам, средняя длина сессии, VDP views в разрезе устройств и источников трафика, описание метрики ym_pv_notBounce, визуализация результатов и гипотезы для маркетинга.

**Стэк:** SQL, Google BigQuery, Яндекс.Метрика Logs API

**Сфера деятельности:** автобизнес, интернет-сервисы, маркетплейсы объявлений.

**Направление деятельности:** веб-аналитик, маркетинг-аналитик, продуктовый аналитик, Data Analyst.

---

#### [Исследовательский анализ e-commerce данных](https://github.com/DmitryBekov7/Data_Analytics-Portfolio/tree/main/ecommerce-data-analysis)

Проект, демонстрирующий навыки исследовательского анализа данных (EDA), работы с продуктовыми метриками интернет-магазина и подготовки выводов для бизнеса. В работе — очистка данных, расчёт метрик, визуализация и интерпретация результатов.

**Стэк:** Python, Pandas, Matplotlib, Seaborn

**Сфера деятельности:** e-commerce, интернет-магазины.

**Направление деятельности:** Data Analyst, продуктовый аналитик, маркетинг-аналитик

---

#### [Анализ индекса промышленного производства Свердловской области](https://github.com/DmitryBekov7/Data_Analytics-Portfolio/tree/main/Sverdlovskstat)

Аналитическая работа на основе данных Свердловскстата: расчёт цепных и годовых индексов по отраслям промышленности, оценка динамики, выявление сезонных колебаний и аномальных всплесков, анализ связи годовых и месячных индексов, построение прогноза и подготовка аналитического заключения с визуализациями.

**Стэк:** Python, Pandas, Matplotlib, Seaborn

**Сфера деятельности:** государственная статистика, промышленность, экономика региона.

**Направление деятельности:** экономический аналитик, Data Analyst.

### Проекты по NLP и машинному обучению
#### [NLP: классификация фейковых новостей](https://github.com/DmitryBekov7/Data_Analytics-Portfolio/tree/main/NLP_Fake_news)

Проект, демонстрирующий навыки работы с текстовыми данными: EDA датасета новостей, проверка баланса классов и дубликатов, очистка текста от HTML и шумов, нормализация, обработка сокращений, удаление стоп-слов, токенизация и padding последовательностей для Keras. Подготовка данных к бинарной классификации REAL/FAKE.

**Стэк:** Python, Pandas, NumPy, NLTK, BeautifulSoup, TensorFlow/Keras, scikit-learn, Matplotlib, Seaborn

**Сфера деятельности:** медиа, NLP, машинное обучение.

**Направление деятельности:** Data Analyst, NLP-аналитик, аналитик-универсал.
